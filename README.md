# زاد المسلم (Zad Al-Muslim) 🕌
> **«زادُ قلبك، ونورُ دربك»**

تطبيق إسلامي أندرويد متكامل وشامل تم بناؤه بأحدث تقنيات أندرويد الرسمية باستخدام **Kotlin** و **Jetpack Compose** بنمط **Material Design 3 (M3)** وواجهة عربية كاملة باتجاه **RTL**.

---

## 🌟 مميزات وأقسام التطبيق

1. **المصحف الشريف (القرآن الكريم):**
   - فهرس كامل لجميع سور القرآن الكريم الـ (114) سورة مع عدد الآيات ونوع النزول (مكية / مدنية) ورقم الجزء والصفحة.
   - نص قرآني موثوق بالرسم العثماني وعلامات الوقف والتشكيل الدقيق بلون موحد مريح للعين.
   - تفسير ميسر ومعاني الكلمات عند النقر على الآية الكريمة.
   - إمكانية تكبير وتصغير حجم خط المصحف لراحة القراءة.
   - حفظ آخر موضع قراءة (علامة قراءة) واستئناف التلاوة بضغطة زر واحدة من الشاشة الرئيسية.
   - التنقل السلس بين السور والآيات.

2. **الأذكار والأدعية (حصن المسلم):**
   - أذكار الصباح والمساء، أذكار بعد الصلاة، أذكار النوم والاستيقاظ، وأدعية قرآنية ونبوية مأثورة.
   - نصوص مضبوطة بالتشكيل مع فضائل الأذكار وتخريج الأحاديث من كتب السنة المعتمدة.
   - عداد تفاعلي لكل ذكر مع شريط إنجاز وتغذية راجعة بالاهتزاز (Haptic Feedback) عند إتمام الذكر.
   - إمكانية البحث الفوري في نصوص وفضائل الأذكار.
   - حفظ الأذكار المفضلة محلياً في قاعدة بيانات الجهاز.

3. **المسبحة الإلكترونية الذكية:**
   - قرص تسبيح تفاعلي فخم بحواف مذهبة ولمسات إسلامية.
   - صيغ تسبيح جاهزة (سبحان الله، الحمد لله، الله أكبر، لا إله إلا الله، أستغفر الله، الصلاة على النبي).
   - دورات تسبيح محددة (33، 99، 100) أو تسبيح حر مفتوح.
   - حفظ العداد تلقائياً عند إغلاق التطبيق واستعادته عند إعادة الفتح.
   - إحصائية للمجموع التراكمي للتسبيحات.
   - تفعيل أو تعطيل الاهتزاز مع إمكانية التصفير.

4. **تنبيهات أذكار الصباح والمساء:**
   - نظام تنبيهات وإشعارات حقيقي متكامل عبر `AlarmManager` و `NotificationManager`.
   - تخصيص وقت التنبيه بدقة لكل من أذكار الصباح والمساء.
   - دعم كامل لأذونات أندرويد الحديثة (`POST_NOTIFICATIONS`).
   - إمكانية إرسال إشعار تجريبي فوري للتحقق من عمل النظام على الهاتف.
   - فتح شاشة الأذكار مباشرة عند الضغط على الإشعار.
   - إعادة جدولة التنبيهات تلقائياً حتى بعد إعادة تشغيل الهاتف (`RECEIVE_BOOT_COMPLETED`).

5. **التقويم الهجري والمناسبات الإسلامية:**
   - عرض متزامن للتاريخ الهجري والميلادي مع اسم اليوم والشهر.
   - حساب تقويمي خوارزمي دقيق يعمل 100% بدون إنترنت.
   - إمكانية تقديم أو تأخير التاريخ الهجري يوماً أو يومين لتطابق رؤية الهلال حسب كل بلد.
   - شبكة أيام الشهر مع تمييز اليوم الحالي والأيام البيض (13، 14، 15) المستحب صيامها.
   - دليل المناسبات الإسلامية الكبرى طوال العام (عاشوراء، المولد، الإسراء والمعراج، رمضان، ليلة القدر، العيدين، عرفة، التشريق) مع شرح وافٍ لكل مناسبة.

6. **التلاوات الصوتية ومشغل القرآن:**
   - مشغل صوتي متكامل بتلاوات خاشعة لنخبة من كبار القراء، وعلى رأسهم الشيخ ياسر الدوسري، مشاري العفاسي، عبد الباسط عبد الصمد، سعد الغامدي، وماهر المعيقلي.
   - مصادر صوتية حقيقية وعالية الجودة من خوادم شبكة MP3Quran المعتمدة.
   - شريط تقدم، تحكم بالتشغيل والإيقاف المؤقت، والتنقل بين السور.
   - إمكانية تنزيل السور للاستماع إليها لاحقاً بالكامل دون الحاجة إلى اتصال بالإنترنت.
   - إدارة السور المحملة وحذفها لتوفير مساحة الهاتف.

7. **العمل دون إنترنت (Offline-First):**
   - جميع البيانات الأساسية، الأذكار، المصحف، التقويم، المسبحة، والإعدادات مخزنة محلياً وتعمل في وضع عدم الاتصال.

## 🚀 كيفية بناء ملف APK وتثبيته على هاتفك عبر GitHub Actions

إذا كنت تستخدم الهاتف المحمول فقط، يمكنك بناء التطبيق والحصول على ملف APK وتثبيته في دقائق باتباع الخطوات البسيطة التالية:

### الخطوة الأولى: رفع المشروع إلى حسابك في GitHub
1. من واجهة **Google AI Studio** أو بيئة العمل الحالية، قم بتصدير المشروع أو رفعه إلى مستودع (Repository) جديد في حسابك على **GitHub** (يمكن أن يكون المستودع عاماً Public أو خاصاً Private).

### الخطوة الثانية: تشغيل البناء التلقائي في GitHub Actions
1. افتح متصفح هاتفك أو تطبيق GitHub وتوجه إلى صفحة المستودع الخاص بك.
2. اضغط على تبويب **Actions** في القائمة العلوية للمستودع.
3. ستجد سير العمل المُعد مسبقاً بعنوان: **`Build Zad Al-Muslim APK`** (موجود في المسار `.github/workflows/android.yml`).
4. يبدأ البناء تلقائياً بمجرد رفع الكود (Push)، أو يمكنك الضغط على **`Run workflow`** لتشغيله يدوياً في أي وقت.

### الخطوة الثالثة: تنزيل ملف APK على هاتفك
1. بعد اكتمال البناء وظهور علامة الصح الخضراء (تستغرق عادة 2-4 دقائق)، اضغط على التشغيل المكتمل.
2. انزل إلى قسم **Artifacts** في أسفل الصفحة.
3. ستجد ملفاً باسم **`ZadAlMuslim-v1.0-Debug-APK`**.
4. اضغط عليه لتنزيل ملف الأرشيف المضغوط (ZIP) إلى هاتفك.
5. افتح مدير الملفات في هاتفك، فك الضغط عن الملف، وستجد بداخله ملف `app-debug.apk`.
6. اضغط على ملف الـ APK لتثبيته فوراً على هاتفك واستمتع بتطبيق «زاد المسلم».

## 🛠 التقنيات المستخدمة في المشروع

- **لغة البرمجة:** Kotlin 2.2
- **واجهة المستخدم:** Jetpack Compose (Material 3)
- **الهندسة المعمارية:** MVVM (Model-View-ViewModel) + Repository Pattern
- **قاعدة البيانات المحلية:** Room Database + KSP
- **التخزين المحلي:** SharedPreferences & Room
- **تشغيل الوسائط:** Android MediaPlayer Framework
- **الجدولة والتنبيهات:** AlarmManager & NotificationCompat
- **سير عمل البناء الآلي:** GitHub Actions (Ubuntu, JDK 17, Gradle 9.3.1)
